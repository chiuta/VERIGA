# Politica de securitate / Security policy

**RO.** Raportează vulnerabilitățile în privat (nu într-un issue public), cu pași de reproducere, versiune și sistem. Vezi secțiunea „Securitate și model de amenințare” din `README.md` pentru ce este în/în afara scopului (anti-SSRF, anteturi sensibile, filtrul de injecție la remedieri, `sendmail`, CORS în varianta web).

**EN.** Please report vulnerabilities privately (not in a public issue) with reproduction steps, version and platform. See “Securitate și model de amenințare / Security & threat model” in `README.md` for scope and known limits.

Versiuni suportate / Supported: ultima versiune minoră / latest minor release.
